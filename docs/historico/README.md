# Documentación histórica — Moodle Course as Code

Documentos del sistema anterior, que publicaba Books en `mod_book` a partir
de manifests `course.yml`/`book.yml` (engine con renderer, catálogo,
planner/executor de despliegues, releases y web services
`local_courseascode_*`).

**Ese flujo se eliminó del código el 2026-11-19** (plugin 2.1.0, engine
2.0.0). Estos documentos se conservan solo como contexto de las decisiones;
no describen el sistema actual. El sistema vigente está en
[../desarrollo-liaeditor-moodle-v1.md](../desarrollo-liaeditor-moodle-v1.md).

- Especificación v0.2 y diagramas de secuencia.
- Tasklist del engine (ENG-001–106) y de pruebas alpha (PRU).
- Guía de autor y guía de operación del flujo `mod_book`.
- Prompt inicial del proyecto (Beta 0.1).
